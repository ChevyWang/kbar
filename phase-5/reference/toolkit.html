节奏最低剂量：按信号下单、记录、打分——不加看盘、不深夜复盘、不逛论坛

五陷阱参数热改 / 信号挑食 / 回本幻觉 / 叙事绑架 / 孤证止损——识别即记录，不对抗
④ 升仓阶梯分数门在 R 门之前；降级是保护不是惩罚
L1 模拟名义 1%。门：4010 毕业 + 一页纸 v1.0。验收：30 笔、均分 ≥85、检查单 ≤30 秒。
L2 小仓0.25%。门（30 笔）：均分 ≥85 且无第 4/7 项丢分；R 无失控（≤回测同参+2R）。降级：均分 <75 两月 → 回 L1 十笔。
L3 计划0.5% → 1%（每次 +0.5%）。门（30 笔）：均分 ≥90、滚动期望 >0、主偏差两月零事故。降级：回撤协议查出数据/市场问题或持续未知 → L2。
记录四列记分卡分（明细）/ 情绪标记 / 检查单耗时 / 滑点实测（挂单价 vs 成交价）——L2 起滑点有自己的分布。
