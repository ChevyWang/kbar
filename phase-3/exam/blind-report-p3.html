盲图报告：给形态发统计身份证

P2 考场考「画地图」，本考场考「报数字」：一张未知品种的日线窗口（55 根，右端出现一个形态）。任务=写出该形态的完整统计预期备忘录——查表员报数字，分析师报条件。限时 50 分钟，可打印。前置：3001–3007 全部结业。

01盲图

品种与时段已隐去。看右端：一个正在发展的底部形态。先写第 02 节，再开第 03 节自评。

02写作任务（50 分钟）

题目：就右端形态写出交易台备忘录。六段（对应六维量规）：

  1. 形态指认：这是什么形态？严格口径的参数过线了吗（写出判别要素）？
  2. 统计身份证：报出该形态的基线数字——突破方向占比、平均行程、失败率（Bulkowski 口径 + 课程 33 品种扫描口径，注明样本与口径声明）
  3. 过滤三问：参数过线了吗 → 位置说得通吗（用 P2 的地形证据答这一问）→ 确认来了吗
  4. 逐根证据：右端至少 2 根K线的 bar-by-bar 解读支撑你的方向判断（P1 语言）
  5. 失效条件：什么情况说明这个形态正在失败？失败后的最小反向目标怎么定（3004）？
  6. 操作含义：等确认还是已可行动？触发价/止损价/初步目标怎么放？

维度0 分1 分2 分

④ 操作含义无操作内容有方向无价位触发/止损/目标齐备

通过线：≥8/12。低于 8 分：回 3002 统计身份证总表与 3005 过滤三问，隔天换图重考。

参考作答框架（骨架，非唯一答案）

右端为双底（W 底）候选：两次探底、右底不低于左底、颈线待破。严格口径需明确「低点间隔/两底深度差/颈线定义」——参数口径必须写死。统计基线（Bulkowski v3 A股口径需换算声明）：双底突破向上占多数、平均涨幅中个位数、失败率约两成且「跌破右底」为硬失效——本课口径以 33 品种扫描表为准引用。过滤三问：参数（右底略高于左底，过线）；位置（日线处于长期下跌后低位+底部量能萎缩，地形支持反转剧本——引用 P2 证据）；确认（颈线带量收盘突破才有资格，未确认前只是候选）。逐根：右底后第一根阳线量能温和放大（需求试探），尚未出现确认棒。失效：跌破右底低点即失效，最小反向目标=形态高度向下投影。操作：观望等确认；触发=带量收盘破颈线，止损=右底下方，初步目标=颈线+形态高度。
