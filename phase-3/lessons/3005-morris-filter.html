Morris 过滤思想与课程改编

Greg Morris《Candlestick Charting Explained》第 7–9 章（可靠性 / 表现 / 过滤）是蜡烛形态从"词汇表"变成"决策系统"的工程蓝图，而 Phase 0 的三合一检查（形状×位置×确认（confirmation））是本课程改编。本课区分原著与改编：Morris 的过滤框架 + 我们的跨市场蜡烛统计（33 品种×5 年的频率与次日表现）。本课约 65 分钟。

01Morris 的过滤哲学 ≈8 min

Morris 在第 7 章（Reliability of Pattern Recognition）直面了本阶段的核心问题：同一个名字下，参数过线与否的形态表现天差地别——"长得像锤子"和"满足锤子参数"是两个总体。第 9 章（Candle Pattern Filtering）给出工程答案：形态触发后不立即行动，先过过滤器（他用的主过滤器包括趋势语境与确认线；第 8 章给表现基线）。

这与我们 0002 就教的"三合一检查"（形状→位置→确认）完全同构——形状→位置→次日确认是课程改编；原著Ch.9围绕指标预信号区域与蜡烛触发。差别在颗粒度：他的书给了参数表（影线（shadow）/实体的比例阈值），我们补上跨市场统计。

02过滤三问：参数、位置、确认 ≈10 min

层问什么Phase 0–2 对应不过滤的后果
①参数形状过线吗（影线≥2×实体、收位、母线（mother bar）包容）0001/0002 的度量"像"锤子的弱样本稀释统计
②位置出现在趋势后还是半空（锤子在跌后=锤子，在涨后=上吊）0003 位置语法同形异位互相抵消，胜率归零
③确认次日朝形态方向收盘了吗0002§05 确认形态是预警不是信号，裸触发≈抛硬币+滑点

三问是串行的：任何一问不过，后面的问都不用问。这也是复盘模板（0007/3.0）里"三合一检查"一栏的由来，它不是清肠仪式，是 Morris 工程的日常运转。

03我们的蜡烛统计：频率与次日表现 ≈10 min

对 33 品种×5 年日线跑 Phase 0 的形态检测器（口径同前：趋势语境+参数硬线），统计每个蜡烛形态的出现频率与次日顺形态方向收板的比率（注意：这是描述统计，不是策略收益）：

形态样本（全部市场）次日顺向收板率对照硬币
看涨吞没（Engulfing）（参数过线+跌后）53853–56%（A股偏高）+3–6pt
锤子（参数过线+跌后）61951–54%+1–4pt
流星（参数过线+涨后）85450–52%（反向）±0–2pt
内包日（Inside Bar）（任意位置）1638≈49–51%±0pt

带读：

  • 参数过线后次日顺向约 51–56%——有信息，但远非信号（这不是Marshall的策略回测复现；次日方向比例与净收益不是同一估计对象）。
  • 内包日"本身"零方向（它是波动率事件不是方向事件——0002 的教学在统计上成立）。
  • A股吞没次日顺向略高的机制候选：涨跌停限制压缩了当日反应、把动量推给次日（机制假设，待更大样本）。

过线只是入场券，三问的后两问才是分数所在。

04跨市场对比：同一根锤子的三张脸 ≈8 min

Phase 0 实例库的三张锤子（赛力斯/英伟达/茅台缩量新高对照）按统计视角重读：次日表现分别是顺向、顺向、中性——样本量为3时比例不稳定，仍可用于标注与规则学习，这三张图的教学价值在"参数都过硬、次日各自不同"这个事实本身：过滤三问的前两问都过了，第三问（确认）才是分水岭。

05过滤工程的组装：从形态到信号 ≈9 min

完整管线：检测（参数）→ 语境（位置/趋势/量能（volume））→ 确认（次日收盘）→ 事件（记录）→ 统计（分桶复盘）。每一层都有"通过/不通过"的硬判据，且每层通过后都要记录剩余样本数——蜡烛候选总体N（不能混用几何形态3594例）→ 过参数剩多少 → 过语境剩多少 → 过确认剩多少：没有这条"分母流"，最后剩下的百分比就无从复核，也无法发现某一层其实在偷偷丢样本。

任何人按同一管线跑同一数据得到同一结果——这就是与"千人千面画线"的工程学分界。你的复盘事件日志（0007/3.0 模板）就是这条管线的日常输出；3006 课你将亲手跑一遍完整管线。

时点协议：若用次日收盘作确认，信号的参考时点必须移到次日收盘之后，结果窗从其后第一根开始；不能筛出次日上涨的样本再假设前日收盘入场。对每层保存N、排除原因、F5/H20四格与区间；未改善或不足也是合格研究结论。上表旧蜡烛比例的完整生成器尚未定位，只可作历史读表素材，不能视为已复现的过滤优势。

06亲手核对 + 训练场 ≈12 min

07小结 ≈2 min

本课带走：

  • Morris 三章（可靠性/表现/过滤）与三合一检查的同构关系。
  • 过滤三问串行（参数→位置→确认），一问不过全盘不用。
  • 我们的蜡烛统计：过线形态次日顺向 51–56%（有信息非信号）、内包零方向、A股吞没的机制候选。
