§双K形态↑

看涨/看跌吞没（抱线）P0Engulfing
前后实体方向相反，后实体包住前实体；严格两端超出与宽松允许端点相等须声明。同向扩大不算反向吞没，统计反转率不等于交易胜率。
判据前后实体方向相反；第二根实体从上方和下方两端全包第一根实体，只包一半不算；两根等长实体互相咬合是拉锯不是吞没。吞没比的是实体对实体，影线越界不影响判定。严格口径（Nison，跳空市场）要求第二根开盘低于前收；连续市场（加密 7×24）用宽松口径，底端相等视为通过。先问：这是跳空市场还是连续市场？
反例与易混十字星被吞几乎自动成立（第一根实体≈0），信息量趋近一根大阳线本身。同向扩大不是反向吞没。与内包日 / 孕线对称相反：吞没比实体（进攻），内包比高低点（收缩）。位置改写含义：支撑上的吞没=高价值反转组合；涨到阻力位的看涨吞没是追高信号，位置减分。
统计Bulkowski 实测（第 0002 课引用）：看涨吞没 63% 反转率，103 个蜡烛形态中排名第 84、频率第 12，最常见，几乎最没用；表现最好的场景反而是熊市里向下突破。

反例与易混锤子线与上吊线完全同形，名字由位置给出：下跌末段=锤子（供给枯竭），上涨末段=上吊（承接裂缝），背后的存量情绪完全不同。两边影线都长=拉锯（十字星家族），不是 Pin。高位长下影只说明下方有人接，接得住接不住要看下一天。

§位置与水平位↑

支撑区 / 阻力区P0Support / Resistance
需求/供给反复出现的区域。画区域不画线，判定看实体收盘。
判据支撑=下方需求反复出现的价格区域，阻力=上方供给反复出现的区域。画区域不画线：同一条阻力七次触碰的实际高点可散布在数十点带宽里，判定标准从「碰到线没有」升级为「实体有没有收在区域外」。影线穿透不等于突破。水平位来源按重要性：前高前低（=摆动点）、整数关口、成交密集区。
反例与易混精确到个位的线会把正常散射误读成突破/跌破。消耗效应双刃：前两三次干净拒绝=验证；第五六次越来越勉强、影线越穿越深=弹药耗尽、突破临近。被突破的阻力变未来的支撑（角色互换）。三种机制（记忆/订单聚居/自我实现）指向同一区域时，判定优先级高于任何单一证据。

消耗效应P0Exhaustion
每次触碰都在消耗守方挂单：前几次干净拒绝=验证；多次勉强拒绝=突破临近。（区别于 Wyckoff 的 absorption）
假突破 / 陷阱P0Fakeout / Trap
影线刺穿或短暂收破后收回。空头陷阱=spring。判定看收盘。
判据影线刺穿区域上沿、实体收不出去=假突破；判定永远看收盘，不看盘中、不看影线。更狠的版本：实体收破一天、次日直接收回区域内=牛市陷阱；镜像（跌破支撑后收回）=熊市陷阱，往往是加速上涨的起点。空头陷阱即 spring。
反例与易混假突破的判据从来不是「破了」，而是「破了之后收盘站在哪、量能怎么配合」：真突破=收盘站上区域上沿，最好带放量、大实体与随后回抽被托住。机制：区域上方堆着做空者的止损单，一波推升吃掉止损制造突破假象（止损猎杀），随后真实供给把价格砸回。
统计课程扫描（33 品种×5 年、3594 例，第 3002 课口径）：十形态的突破失败率（头 5 根收回）聚在 40–55%——「刺穿后收回」是基线事件而非例外，形态名几乎不改变这个基线。

反例与易混与失败突破的分界是第 1009 课第⑤类：回踩穿透突破位且不收回=突破测试后失守（失败信号）；收回=成功测试。同一事件可以有多个标签，主判据必须先写清盘中越界还是收盘越界——同一根回踩，口径不同判词不同。

§市场结构↑

摆动高点 / 低点P0Swing High / Low
高于/低于左右各 N 根（N 常取 3–5）的极值。结构的原子，确认滞后 N 根。
判据高点高于左右各 N 根（本课程 N=3，常用 3–5）即为摆动高点，镜像为摆动低点；用影线极值判定，不用实体。N 越大筛出的点越少越重要，N 一旦选定一张图内不换。最新K线永远无法立即确认摆动点，确认要等右侧 N 根——客观性自带的代价。
反例与易混双顶/双底=同一个摆动区的两次触碰（高低点近似，算一个结构位、两个确认）。结构是分形的：日线摆动点在周线可能只是半根K线，同一张图永远多层结构嵌套。摆动低点是支撑的出生证明、摆动高点是阻力的出生证明。逐根比较的局部极值未经确认、随时作废，用于跟踪而非定结构。

带走高于/低于左右各 N 根（N 常取 3–5）的极值。
HH / HL / LH / LLP0Higher High 等
四象限记号。趋势的严格定义=HH+HL 或 LH+LL 交替。
判据把最近的摆动高/低点与前一个同类摆动点比较，只有四种结果。严格定义：上升趋势=HH 与 HL 交替出现的序列（两个都要，只有 HH 没有 HL 的是没有回调的直线，罕见且不稳）；下降趋势=LH 与 LL 交替；震荡=高低点重叠、序列矛盾。跌破最近 HL 用收盘判定，收盘破位才叫 BOS。
反例与易混「上升趋势结束」与「下降趋势开始」是两个事件：前者只需一根收盘破 HL 的K线，后者要求 LH+LL 完整序列，中间过渡状态叫震荡。趋势线是结构的主观衍生品、结构序列是客观的：趋势线被破而结构未破=只是回调加深，永远以序列为准。成色分级：教科书趋势（间距均匀、回调浅）/粗糙趋势（回调深、参差）/早期趋势（新 HH/HL 仅 1–2 组，最优赔率区但最需回抽确认）。

§Phase 1 · 趋势与通道↑

Always-InP1永远在场（Brooks）
市场当前「若被迫持仓只能持哪边」的默认方向。强趋势棒+跟随=翻转；翻转需两次以上证据。
判据问句定义：若此刻强迫你持仓且只能持一边，你只能持哪一边？两票制翻转（课程操作约定，非已核对的 Brooks 原文规则）：一根强逆势棒（大实体、收在方向端、常伴放量）只是候选，不计票，让状态从「确定」降为「存疑」；跟随棒（次日同向推进、不创反向新高新低）是第一票；第二次证据（回踩不破该棒极值、或第二根强棒）完成翻转。顺向可被单根随时加强，逆向翻转必须攒够两次证据。
反例与易混与 Phase 0 结构是同一件事的两副面孔：结构是事后丈量（摆动点确认滞后 3 根），Always-In 是事中直觉（每根K线都在投票）。三个陷阱：把存疑当翻转（一根大阳线全仓翻多是新手亏损第一来源）；区间里强行定向（重叠区间=中性）；忘大周期（日线多+4h 空=日线多头中的 4h 回调，大周期优先）。多项同源价格特征不能当独立概率相乘。

§Phase 1 · 回调与计数↑

突破回踩P1Breakout pullback
突破后的价位测试；区分盘中触及、收盘收回及随后延续，后两项须到各自时点才可判断。
H1 / H2 / L1 / L2P1数腿计数
趋势回调中的尝试计数：H触发看本根H高于前根H，L触发看本根L低于前根L；再次回调后的第二次尝试为H2/L2。信号棒、触发棒与额外收盘过滤分开，不能把上破称L1。
ABC 调整P1ABC correction
回调的三段结构（A 下、B 反、C 再下）——与 H2/L2 是同一现象的两种数法。
二次入场P1Second entry
首次尝试后再出现的机会；分别按当时入场、止损、目标量距。二次可能更差、失败或根本不给机会，不保证止损减半。
楔形 / 三推P1Wedge / Three-push
同向三段推进，中间须有可识别反向回调；注明尺度与分段。第三推收弱可列反转候选，不能证明三层订单耗尽或保证方向。
信号棒 / 入场棒P1Signal / Entry bar
信号棒=给出条件的棒；入场棒=触发条件的下一棒。好信号棒收在其方向端。
跟随棒P1Follow-through bar
信号之后提供同向推进的新证据；形成当刻不可提前引用，缺少跟随不等于必然失败。

§Phase 1 · 目标与磁吸↑

量度目标P1Measured move
从截至当时已知锚点按腿长或区间高度计算的候选位置；注明公式与可知时点，不承诺到达或减速。
磁吸P1Magnet
候选观察位置的比喻，如已知量度目标、前极值、整数关。不能由OHLC证明挂单密度或必达；到达后按新证据更新。
缺口 / 缺口棒P1Gap / Gap bar

§Phase 2 · Wyckoff 市场观↑

复合操盘手P2Composite Operator (CO)

§数学与风控↑

R 倍数P4R-multiple
实际净盈亏除以入场前冻结的计划初始风险。缺口、滑点和成本可使止损劣于−1R；不能事后放大分母粉饰结果。4006
判据R 倍数=实际净盈亏÷入场前冻结的计划初始风险（(入场价−止损价)×股数=1R）；分母在入场那刻冻结，之后不动。止损打掉不等于恰好 −1R：跳空穿越止损、跌停无法卖出、滑点都可使实际损失超过 1R；止损前主动离场可亏得比 1R 少。
反例与易混R 化之后跨品种、跨仓位可比（BTC 与茅台同语言），统计可算（胜率与期望直接从 R 列读出）。1R 是预算不是保证，风险预算按「止损可能被执行得更差」留余量。频率伪装的解药：把「应验」翻译成 R 倍数再说话——50% 的方向命中配 1:0.8 的赔率是亏的。

期望值P4Expectancy
互斥交易结果下的加权净R平均；一般形式为各结果概率乘损益的和。描述事件频率不能直接代入，样本均值不等于未来真实期望。4006
判据E = p×平均盈利 − (1−p)×平均亏损（R 计价）；互斥交易结果下=各结果概率乘损益的加权平均。样本均值不等于未来真实期望，仍受依赖、选择、成本及非平稳影响。
反例与易混胜率与盈亏比可交换：33% 胜率×3R 盈亏比与 60% 胜率×1R 可以同期望。期望是均值不是承诺，对任何一笔的答案都是「不知道」。事件频率不能直接代入：达标率/失败率量的是行情不是可捕获收益，要谈期望值必须另立完整交易协议（先触即离场、+2R/−1R 互斥、同棒双触保守计、超时离场、扣费）。正期望很薄：每冒 1R 平均只赚 0.095R，手续费与滑点就能吃掉一半。

§波图（Weis Wave，2009 课）↑

波图 / Weis WaveP2Wave chart
把连续同向价格段聚成一「波」并标注三要素（长度/波量/时长）的读价工具——Wyckoff 磁带阅读图的现代形态。判读只做对比：与前面同向波比。2009
波量P2Wave volume
按冻结分段规则累计波内成交量；尚未确认的波会变化，归属算法不同可能不同。成交量不识别买卖主体真实力量。2009
推程缩短P2Shortening of thrust
同向波的价格行程逐波变短：还在花弹药但推不动价格——直接写在结果上的衰竭信号，与楔形三推（1005）互为印证。2009

§日型（Dalton，2010 课）↑

日型P2Day type
「今天会是哪种交易日」的分类假设（趋势日/双分布趋势/常态变形/常态/中性/无趋势），摆在方向信念光谱上；判型=开盘后尽早定位今天的位置，输出战术清单。2010
判据六型按方向信念光谱排列：无趋势→中性→常态→常态变形→双分布趋势→趋势日；判型五问（开盘 60–90 分钟内完成）：开在哪（价值区内/外）、初始区间宽吗、开盘是极值吗、量能跟上吗、波账怎么说。输出三选一假设（趋势家族/区间家族/观望）+对应战术清单；这是假设不是判决，盘中证伪就换剧本。
反例与易混双分布趋势日不是「先趋势、再歇脚、再走一段」：窄初始平衡→早段一次性延伸→新位第二平衡，第二分布是延伸的结果不是休息站。常态变形的延伸常无量能背书，与教科书趋势日的差别就在判型第④问只能加分不能定案。日线外形代理不是 Dalton 日型的测量（日线看不见初始平衡宽窄、延伸时点与双分布过程）；加密 UTC 00:00 切日是分析约定——没有先写死 session/时区/IB 定义的日型统计，数字之间不可比。
统计第 2010 课日线外形代理（XRP 134 天，代理口径不外推为 Dalton 日型频率）：单边+放量外形仅 5 天（3.7%）；窄幅缩量+长影有量外形合计约四成（26.1%+14.2%）；「单边收盘但量平」是「单边+放量」的四倍。

§tilt 系统（Tendler，5007 课）↑

tiltP5Tilt
情绪对决策的实时劫持（梯度上升，不是开关）。两大信号灯：执念（隧道视野）与风险失明（风控规则在认知层消失）。5007
模式地图P5Pattern map
记录触发、情绪、想法与行为后寻找可检验模式；10–20条只是组织练习，不保证规律必然出现。5007
寸进概念P5Inchworm concept
进步=最好与最差表现的整个区间向前挪（尺蠖先收尾再进头）——评估心理进步用「最差日的破坏半径」，不用盈利曲线。5007
实时纠偏四步P5Real-time correction
Tendler 第 9 章：①识别（信号灯）②打断（身体动作外力）③注入逻辑（预制小句）④策略提醒（回到 setup 锚点）。双重收益：纠偏同时攒训练次数→resolution。5007

§输出（Phase 6）↑

五段式备忘录P6Five-part memo
公开行情分析的骨架：结构/证据/概率/操作/风险——与 P2/P3 盲图报告量规同构，证据段最重（≥3 处具体指认）。6001
可证伪标题P6Falsifiable headline
标题=可检验的判断而非悬念（「吸筹区间进入 Phase C」✓「要变盘了！」✗）——两轴矩阵的刀口对准自己。6001
正面镜子P6Positive mirror
Steenbarger：只记错题的日志=自我批评教练，迟早强化无能感——复盘文必须含「做对了什么（证据化）+下月改动一条」。6002
六段复盘模板P6Six-part review
候场→入场逻辑→执行时间线→结果与决策评分（分开报告互不解释）→教训→归档。全程决策质量语言，盈亏只作数据。6002
大纲预审P6Proposal review
MFTA 制度：开工前研究大纲（问题/数据/口径/输出/工作量）须过审——一页纸拦截三个月的沉没成本。6003
可退回重写P6Revise-and-resubmit
MFTA 质量机制：交付不达标打回改到过——退回是流程不是失败；社区检验的预演。6003
选题三型P6Three research types
统计检验型/体系审计型/行为审计型——裁决器：一句话可检验+数据伸手可及，缺一换题。6003
教学文三件套P6Metaphor-example-counterexample
一个比喻（外行入口）+一个真实例子（带日期）+一个反例（防混淆孪生场景）；外行测试=让对方复述，卡壳句重写。6004
