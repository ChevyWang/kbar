§四要素与解剖↑

开盘价P0Open
本周期第一笔成交价。战斗的开局。
收盘价P0Close
本周期最后一笔成交价。一根K线里最重要的数字——判定口径。
最高价 / 最低价P0High / Low
买方推进 / 卖方砸落的极值，上下影线的顶与底。
实体P0Body
开盘与收盘之间的矩形——谁把旗帜插在了战场终点。
上影线 / 下影线P0Upper / Lower shadow
被夺回的领地，战功记防守方（上影记卖方、下影记买方）。
阳线 / 阴线P0Bullish / Bearish
收≥开（买方胜）/ 收<开（卖方胜）。本课程图上阳线空心、阴线实心（空心=涨、实心=跌），单根图另有开=左刻度、收=右刻度。
光头光脚P0Marubozu
无影线或影线极小：开≈最低、收≈最高：净结果一边倒。
十字星P0Doji
收≈开：平局。是「状态」不是「事件」——含义由位置给出。
一字线P0Flat bar
四价合一。A股涨跌停封板特产。

实体占比P0Body ratio
实体÷全长（别名：干净度）。≥65% 一边倒，≤25% 拉锯。
收盘位置P0Close location
（收−低）÷（高−低）（别名：控场度）。≥0.7 收头部，≤0.35 收脚下。

§双K形态↑

看涨/看跌吞没（抱线）P0Engulfing
前后实体方向相反，后实体包住前实体；严格两端超出与宽松允许端点相等须声明。同向扩大不算反向吞没，统计反转率不等于交易胜率。
判据前后实体方向相反；第二根实体从上方和下方两端全包第一根实体，只包一半不算；两根等长实体互相咬合是拉锯不是吞没。吞没比的是实体对实体，影线越界不影响判定。严格口径（Nison，跳空市场）要求第二根开盘低于前收；连续市场（加密 7×24）用宽松口径，底端相等视为通过。先问：这是跳空市场还是连续市场？
反例与易混十字星被吞几乎自动成立（第一根实体≈0），信息量趋近一根大阳线本身。同向扩大不是反向吞没。与内包日 / 孕线对称相反：吞没比实体（进攻），内包比高低点（收缩）。位置改写含义：支撑上的吞没=高价值反转组合；涨到阻力位的看涨吞没是追高信号，位置减分。
统计Bulkowski 实测（第 0002 课引用）：看涨吞没 63% 反转率，103 个蜡烛形态中排名第 84、频率第 12，最常见，几乎最没用；表现最好的场景反而是熊市里向下突破。

锤子线 / 上吊线P0Hammer / Hanging Man
同形不同命：下跌末段=锤子（需求），上涨末段=上吊（供给）。丁圣元归入「伞形线」家族。
流星线P0Shooting Star
上涨末段长上影小实体：上方有供给。
Pin BarP0价格行为社区叫法
影线主导形态统称（Brooks/外汇圈）。主影线≥全长2/3且伸进前几根领地；灵魂在位置。
判据四条全过才算：主影线≥全长 2/3（Bulkowski 口径：下影至少为实体 2–3 倍）；实体小且位于整根K线远端（锤子在上端、流星在下端）；对侧影线极短或没有；影线尖端刺入前低（锤子）或前高（流星），前低=之前最近 3–5 根K线最低价或最近摆动低点。只在自己实体下方晃、没碰到前人阵地（插队）不叫试探被拒。颜色是强弱项不是方向项；上吊线须次日确认（下一根收盘吞掉其实体）才可行动。
反例与易混锤子线与上吊线完全同形，名字由位置给出：下跌末段=锤子（供给枯竭），上涨末段=上吊（承接裂缝），背后的存量情绪完全不同。两边影线都长=拉锯（十字星家族），不是 Pin。高位长下影只说明下方有人接，接得住接不住要看下一天。
统计Bulkowski 实测（第 0002 课引用）：锤子线 60% 反转率，排名 65/103，「离随机（50%）不远」。单看形状≈抛硬币，加位置与确认才是另一回事。

内包日 / 孕线P0Inside Bar; distinct from Harami
内包棒按完整高低范围判定：本课严格口径要求第二根H低于母线H且L高于母线L。Harami（孕线）按实体包容定义，并非Inside Bar的同义词；影线可越母线。仅说明范围收缩，不确定后续突破方向。
判据本课严格口径按完整高低范围：第二根 H 低于母线 H 且 L 高于母线 L，两条件同时成立。低点刺破母线低点=只是小K线，不是内包日。
反例与易混与 Harami（孕线）不同：Harami 按实体包容定义，影线可越母线，不能代替全范围 Inside Bar。与吞没对称相反：吞没比实体（进攻），内包比高低点（收缩）。本身不指方向，只说明波动率压缩；职业做法标记母线高低点作预写触发线。趋势中的内包（顺势休战）与顶部的内包（动能衰竭）含义不同，等位置与突破裁决。

波动率压缩P0Volatility contraction
连续十字/内包/窄幅的统称：蓄力，方向选择临近。
宽松 / 严格口径P0Loose / Strict criterion
连续市场（开盘≈前收）吞没常见底端相等版=宽松口径；两端都严格超出=严格口径。判定时须声明。
确认P0Confirmation
形态是预警，次日朝形态方向收盘才升级为信号（Morris 过滤法核心）。

§位置与水平位↑

支撑区 / 阻力区P0Support / Resistance
需求/供给反复出现的区域。画区域不画线，判定看实体收盘。
判据支撑=下方需求反复出现的价格区域，阻力=上方供给反复出现的区域。画区域不画线：同一条阻力七次触碰的实际高点可散布在数十点带宽里，判定标准从「碰到线没有」升级为「实体有没有收在区域外」。影线穿透不等于突破。水平位来源按重要性：前高前低（=摆动点）、整数关口、成交密集区。
反例与易混精确到个位的线会把正常散射误读成突破/跌破。消耗效应双刃：前两三次干净拒绝=验证；第五六次越来越勉强、影线越穿越深=弹药耗尽、突破临近。被突破的阻力变未来的支撑（角色互换）。三种机制（记忆/订单聚居/自我实现）指向同一区域时，判定优先级高于任何单一证据。
课次0003 0004
带走需求/供给反复出现的区域。
消耗效应P0Exhaustion
每次触碰都在消耗守方挂单：前几次干净拒绝=验证；多次勉强拒绝=突破临近。（区别于 Wyckoff 的 absorption）
假突破 / 陷阱P0Fakeout / Trap
影线刺穿或短暂收破后收回。空头陷阱=spring。判定看收盘。
判据影线刺穿区域上沿、实体收不出去=假突破；判定永远看收盘，不看盘中、不看影线。更狠的版本：实体收破一天、次日直接收回区域内=牛市陷阱；镜像（跌破支撑后收回）=熊市陷阱，往往是加速上涨的起点。空头陷阱即 spring。
反例与易混假突破的判据从来不是「破了」，而是「破了之后收盘站在哪、量能怎么配合」：真突破=收盘站上区域上沿，最好带放量、大实体与随后回抽被托住。机制：区域上方堆着做空者的止损单，一波推升吃掉止损制造突破假象（止损猎杀），随后真实供给把价格砸回。
统计课程扫描（33 品种×5 年、3594 例，第 3002 课口径）：十形态的突破失败率（头 5 根收回）聚在 40–55%——「刺穿后收回」是基线事件而非例外，形态名几乎不改变这个基线。
课次0003 1009
带走影线刺穿或短暂收破后收回。
止损猎杀P0Stop hunting
影线刺穿明显支撑/阻力（止损单堆积处）后收回——假突破的动机版。
证据重叠P0Confluence
多个独立证据指向同一价位/方向，信号质量加权。
三合一检查P0Shape-Position-Confirmation
形状（参数过线）→位置（语境说得通）→确认（次日收盘）。齐备才行动。
回抽P0Retest
突破后回到被破区域边缘止住——真突破的二次确认。
判据突破后价格回到被突破的区域上沿，再次被托住——真突破的二次确认。课程纪律：判定永远看收盘；突破后等回抽再考虑入场（直接突破是另一方案，须另定风险）；第一次触碰水平位时反应最真实。
反例与易混与失败突破的分界是第 1009 课第⑤类：回踩穿透突破位且不收回=突破测试后失守（失败信号）；收回=成功测试。同一事件可以有多个标签，主判据必须先写清盘中越界还是收盘越界——同一根回踩，口径不同判词不同。

§市场结构↑

摆动高点 / 低点P0Swing High / Low
高于/低于左右各 N 根（N 常取 3–5）的极值。结构的原子，确认滞后 N 根。
判据高点高于左右各 N 根（本课程 N=3，常用 3–5）即为摆动高点，镜像为摆动低点；用影线极值判定，不用实体。N 越大筛出的点越少越重要，N 一旦选定一张图内不换。最新K线永远无法立即确认摆动点，确认要等右侧 N 根——客观性自带的代价。
反例与易混双顶/双底=同一个摆动区的两次触碰（高低点近似，算一个结构位、两个确认）。结构是分形的：日线摆动点在周线可能只是半根K线，同一张图永远多层结构嵌套。摆动低点是支撑的出生证明、摆动高点是阻力的出生证明。逐根比较的局部极值未经确认、随时作废，用于跟踪而非定结构。
课次0004
带走高于/低于左右各 N 根（N 常取 3–5）的极值。
HH / HL / LH / LLP0Higher High 等
四象限记号。趋势的严格定义=HH+HL 或 LH+LL 交替。
判据把最近的摆动高/低点与前一个同类摆动点比较，只有四种结果。严格定义：上升趋势=HH 与 HL 交替出现的序列（两个都要，只有 HH 没有 HL 的是没有回调的直线，罕见且不稳）；下降趋势=LH 与 LL 交替；震荡=高低点重叠、序列矛盾。跌破最近 HL 用收盘判定，收盘破位才叫 BOS。
反例与易混「上升趋势结束」与「下降趋势开始」是两个事件：前者只需一根收盘破 HL 的K线，后者要求 LH+LL 完整序列，中间过渡状态叫震荡。趋势线是结构的主观衍生品、结构序列是客观的：趋势线被破而结构未破=只是回调加深，永远以序列为准。成色分级：教科书趋势（间距均匀、回调浅）/粗糙趋势（回调深、参差）/早期趋势（新 HH/HL 仅 1–2 组，最优赔率区但最需回抽确认）。
课次0004
带走四象限记号。
结构破坏P0BOS
收盘跌破最近 HL：停止顺势的开关；反手要等 LH+LL 完整序列。

§多周期↑

自上而下P0Top-down
大周期定方向→中周期找区域→小周期找时机。顺序不可逆。
三重时间框架P0Triple timeframe
三镜头工作流；协同=最高质量窗口。
周期冲突P0Timeframe conflict

§Phase 1 · 趋势与通道↑

Always-InP1永远在场（Brooks）
市场当前「若被迫持仓只能持哪边」的默认方向。强趋势棒+跟随=翻转；翻转需两次以上证据。
判据问句定义：若此刻强迫你持仓且只能持一边，你只能持哪一边？两票制翻转（课程操作约定，非已核对的 Brooks 原文规则）：一根强逆势棒（大实体、收在方向端、常伴放量）只是候选，不计票，让状态从「确定」降为「存疑」；跟随棒（次日同向推进、不创反向新高新低）是第一票；第二次证据（回踩不破该棒极值、或第二根强棒）完成翻转。顺向可被单根随时加强，逆向翻转必须攒够两次证据。
反例与易混与 Phase 0 结构是同一件事的两副面孔：结构是事后丈量（摆动点确认滞后 3 根），Always-In 是事中直觉（每根K线都在投票）。三个陷阱：把存疑当翻转（一根大阳线全仓翻多是新手亏损第一来源）；区间里强行定向（重叠区间=中性）；忘大周期（日线多+4h 空=日线多头中的 4h 回调，大周期优先）。多项同源价格特征不能当独立概率相乘。

带走市场当前「若被迫持仓只能持哪边」的默认方向。
趋势K线 / 十字K线P1Trend bar / Doji bar
有实体的K线=一方表态；十字=双方观望。连续趋势棒同向=市场在说话。
高潮棒P1Climax bar
超长实体+常伴随天量：动能透支。高潮之后常进入区间（fresh legs rarely follow immediately）。
尖峰与通道P1Spike & Channel
一根（组）爆发棒=尖峰，随后沿通道阶梯推进。通道回撤常至尖峰中部；尖峰起点是趋势的生命线。
微通道P1Micro channel
本课严格口径：看涨连续至少3根低点逐根升高，看跌高点逐根降低；平低/平高不通过。其他口径须另标，不可混用。
宽通道 / 阶梯P1Broad channel / Stairs
回调深但仍有序的趋势：两步进一退。与微通道构成趋势紧度光谱的两端。
趋势化交易区间P1Trending trading range
整体有序推进但每段内部像区间——多数真实趋势的形态，介于趋势与区间之间。

§Phase 1 · 回调与计数↑

突破回踩P1Breakout pullback
突破后的价位测试；区分盘中触及、收盘收回及随后延续，后两项须到各自时点才可判断。
H1 / H2 / L1 / L2P1数腿计数
趋势回调中的尝试计数：H触发看本根H高于前根H，L触发看本根L低于前根L；再次回调后的第二次尝试为H2/L2。信号棒、触发棒与额外收盘过滤分开，不能把上破称L1。
ABC 调整P1ABC correction
回调的三段结构（A 下、B 反、C 再下）——与 H2/L2 是同一现象的两种数法。
二次入场P1Second entry
首次尝试后再出现的机会；分别按当时入场、止损、目标量距。二次可能更差、失败或根本不给机会，不保证止损减半。
楔形 / 三推P1Wedge / Three-push
同向三段推进，中间须有可识别反向回调；注明尺度与分段。第三推收弱可列反转候选，不能证明三层订单耗尽或保证方向。
信号棒 / 入场棒P1Signal / Entry bar
信号棒=给出条件的棒；入场棒=触发条件的下一棒。好信号棒收在其方向端。
跟随棒P1Follow-through bar
信号之后提供同向推进的新证据；形成当刻不可提前引用，缺少跟随不等于必然失败。

§Phase 1 · 目标与磁吸↑

量度目标P1Measured move
从截至当时已知锚点按腿长或区间高度计算的候选位置；注明公式与可知时点，不承诺到达或减速。
磁吸P1Magnet
候选观察位置的比喻，如已知量度目标、前极值、整数关。不能由OHLC证明挂单密度或必达；到达后按新证据更新。
缺口 / 缺口棒P1Gap / Gap bar
开盘跳空比较本根O与前根C；全范围缺口要求本根L>前根H或本根H<前根L。未回访价区不等于缺口；均线相关gap bar另需相应先修，本课不混用。
二十缺口棒P1Twenty gap bars
旧版将某价位20根未触及归为Brooks缺口规则，出处未核且概念混用，现撤下。只能记录某起点之后截至当前的未回访区，不推出必回补。

§Phase 1 · 画线工具↑

趋势线（内涵/外延）P1Trend line (Inner / Outer)
连摆动点的直线（外延）或穿多数棒身忽略毛刺（内涵）。回踩线=顺势窗口；破线=单边松动信号；每次破线后新线更平=动能衰减。Brooks Trends Ch.13。
趋势通道线P1Trend channel line
趋势线的平行线拖到对侧。第一减仓位/最小目标；过冲=高潮预警；上升通道整体=熊旗。Ch.14。
通道过冲P1Overshoot
加速穿过通道线——常是高潮，随后跌回甚至穿过通道底。通道线作为减仓位的理由。
斐波那契回撤P1Fibonacci retracement
38.2/50/61.8% 的腿比例分割——量度目标家族的比例尺。与水平位/目标重叠才加权，单独不下注，画区域不画线。

§Phase 1 · 突破与失败↑

失败突破P1Failed breakout
突破后 1–3 根内跌回突破位：不是噪音，是反向信号（ trapped 一方认输）。强失败=强反向预期。
判据五类目录，一律收盘判定+1–3 根时间窗（拖过三天再跌回不算失败突破，算新行情）：影线假突破（刺穿水平位收回）；收盘失败突破（收盘越位后 1–3 根内收盘跌回）；突破后直接回吐（次日吞没突破棒）；二次冲高失败（再试不创新高/新低）；突破测试后失守（回踩穿透突破位且不收回）。反向最小目标两把尺取其合理者：小型失败用失败棒极值到突破位的投影，大型失败用形态起点到失败极值的整段。
反例与易混不是噪音，是反向信号（trapped 一方认输）；但 OHLCV 不能数出被困人数，也不能证明所有参与者同时被套。二次失败（同一方向连续两次）=强反向信号；失败链语法：首试失败→反弹/回落蓄力→二试失败→反向启动。与回抽互为对照组：收回=成功测试，不收回=失守。
统计课程扫描 3594 例（第 3001 课口径：33 品种×5 年、收盘突破、5 根窗）：失败两格合计 1735/3594（48.3%）——「突破后 5 根内收回」是基线事件；四格分布 1308/427/1055/804（36.4/11.9/29.4/22.4%），失败与达标是分别定义时窗的事件，不互补。

突破测试P1Breakout test
突破后回踩至突破位（常略穿透）再收回——测守方残余。测试成功=趋势更健康。
双顶/双底旗P1Double top/bottom flag
回调中的双顶=看跌旗，双底=看涨旗——趋势中的休整形态而非反转。
判据回调中出现的双顶=看跌旗，双底=看涨旗：判定对象是趋势回调内的两次触碰，旗的突破方向与原趋势同向。
反例与易混与反转形态的双顶/双底区分在位置：趋势回调中=休整旗（顺势）；顶部/底部区间末端的=反转候选（第 3002 课统计表测的是后者：双底 N=87–299、失败率 44–51%、达标率 40–54%）。日线级旗形（强位移+浅回撤）本就稀有，3002 课口径下仅 19 例，统计仅作存在性证明；它与 spike & channel 是同一现象的形态学名字。

§Phase 1 · 区间↑

紧交易区间P1TTR (Tight trading range)
连续多根小实体、高低点重叠的极窄区间：磁吸+突破酝酿。突破常直接走完（磁吸释放）。
判据连续多根小实体K线、高低点完全重叠、区间高度相对行情微不足道（实例口径：全距/均幅≈1.7–2.5）。TTR 期间市场在换手定价权。突破常直接走完：一两天内到达量度目标、中途几乎不回调——操作上突破棒不等回踩，止损只能放 TTR 另一侧。
反例与易混压缩质量差的小实体群（实体不小）不配「一步到位」。没有近距磁铁的压缩可以不突破或走不远：对照案例里上方前高远在 130 点外、下方整数关+双底的磁力更强，方向选择向下且走不远。与磁吸一体两面：压缩把价格攥在手里，松手时一次送达；奔向磁铁途中一切逆向形态先按回调处理，磁铁不是墙，是收费站。
