Nison 形态族谱

蜡烛图形态的中文命名以 Nison《日本蜡烛图技术》第 2 版（丁圣元 译）为准——本页是全家族的名录与对照。正课只精读了少数母题，其余形态到「认名 + 知道机制一句话」即可；名字不是能力，位置和量能才是（见第 0003/0005 课）。

译名对照三处易混（本站课件用词 → 丁译）：
  • 内包日（Inside Bar）≠ 孕线形态（Harami）
  • 缺口 = 窗口（Window，课程在 Phase 1 第 1007 课用「缺口分类学」称呼并按四型处理）
  • 锤子线/上吊线（Hanging Man）= 伞形线家族（同一根线，位置定名）
读任何中文技术分析材料遇到异名，先在此页对齐。

一、反转家族 · 单K与双K

形态（丁译 / 英文）机制一句话正课对应
伞形线Umbrella长下影+小实体：一个价格试探区内被拒绝的位置。下跌末端=锤子线，上涨末端=上吊线——同形不同命，位置定名。精读0001 单K三问 / 0002 位置决定含义
吞没形态（抱线）Engulfing后一根实体包住前一根：主动权完全易手。阴包阳=看跌吞没，阳包阴=看涨吞没。精读0002 双K三母题之首
乌云盖顶Dark Cloud Cover高开上行、收盘扎入前阳实体下半部——买方推力被卖方反手夺回大半；吞没的「打折版」。认名机制=吞没家族变体（0002 的确认思想 confirmation）
刺透形态Piercing Pattern低开上行、收盘扎入前阴实体上半部——乌云盖顶的镜像，看涨。认名同上（镜像关系）

二、星线家族（三K反转）

形态机制一句话正课对应
星线Star小实体与前后实体之间有跳空：原有推进第一次「断电」。认名小实体=犹豫（0001 干净度反读）
启明星 / 黄昏星Morning / Evening Star推进→断电→反向收复：三段式权力交接。黄昏星=启明星镜像。认名结构=三段反转剧本
十字启明星 / 十字黄昏星Doji Morning / Evening Star中段换成十字线：断电更彻底，反转证据更强。认名十字=极致犹豫（0001 边界情况）
流星形态Shooting Star长上影+小实体居低端：高位冲高被拒——伞形线的倒影。精读0001/0002（Pin Bar 上影版）
倒锤子Inverted Hammer下跌末端的长上影小实体：试探性买方首次抬头，需次日确认。认名需确认思想（0002）

三、其他反转形态

形态机制一句话正课对应
孕线形态Harami ≠ 全范围内包日后一根实体被前一根实体包住，影线（shadow）可越界：推进急刹车，动能骤降。精读0002 §04 内包日
平头顶部 / 平头底部Tweezer Top / Bottom两根K线高点（低点）几乎同价：同一位置两次拒绝。认名双重拒绝=区域证据（0003）

向上跳空两只乌鸦Upside Gap Two Crows上跳空后连续两阴未能回补：买方跳空的成果被逐步蚕食。认名缺口+侵蚀（1007/1009 失败突破）

圆形顶 / 平底锅底Rounding Top / Frying Pan Bottom渐进的弧形动能衰减/积累：慢变量，适合区间市场。认名—

怎么用这页：
  • 读中文材料遇形态异名 → 在此对齐丁译与机制。
  • 任何形态的统计身份证（胜率/失败率/失效条件）见 Phase 3 形态统计总表——名字永远不是下单理由。
  • 精读标记的形态在正课有完整教学，认名标记的只需记住「机制一句话」。
