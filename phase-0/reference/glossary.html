术语手册

全七课词汇。所有课件遵照本表用词——打印出来贴在手边。

01四要素（第 0001 课）

开盘价 Open
本周期第一笔成交价。战斗的开局。
收盘价 Close
本周期最后一笔成交价。战斗结束时的地盘——一根K线里最重要的数字，因为它是唯一"存活"到下一根K线的价格；一切水平位与结构的判定口径。
最高价 High
周期内买方推进到的最远处。上影线的顶。
最低价 Low
周期内卖方砸到的最远处。下影线的底。

02解剖结构（第 0001 课）

实体 Body
开盘价与收盘价之间的矩形。谁的旗帜插在了战场终点。
上影线 Upper shadow
最高价到实体上沿。买方曾推进、后被卖方夺回的领地——上方存在供给的记录，战功记卖方。
下影线 Lower shadow
实体下沿到最低价。卖方曾砸落、后被买方全数接回的领地——下方存在需求的记录，战功记买方。
阳线 / 阴线 Bullish / Bearish
收 ≥ 开（买方胜）/ 收 < 开（卖方胜）。红涨绿跌与绿涨红跌两种配色都必须秒读；本课程图上阴线一律空心实体——颜色之外的第二重方向编码。
光头光脚 Marubozu
无影线或影线极小：胜方从头压到尾，几乎无抵抗。
十字星 Doji
收 ≈ 开：平局。是一个"状态"不是"事件"——连续出现=压缩蓄力；含义由位置给出。
一字线 Flat bar
开=高=低=收，全天单一价位。A股涨跌停封板特产；信息在K线外（封板力量与排队）。

03两个度量（第 0001 课）

实体占比 Body ratio
实体 ÷ 全长（高−低）。胜负的干净程度（别名：干净度）：≥65% 一边倒，≤25% 拉锯。
收盘位置 Close location
（收−低）÷（高−低），0~1。控场程度（别名：控场度）：≥0.7 收在头部，≤0.35 收在脚下。与实体占比连读。

04双K形态（第 0002 课）

看涨吞没 Bullish Engulfing
下跌后：小阴线 + 大阳线，第二根实体上下两端全包第一根实体（影线不要求）。买方全面反攻。实测 63% 反转率、排名 84/103——常见但单独使用很弱。
看跌吞没 Bearish Engulfing
镜像：上涨后小阳线 + 大阴线全包。卖方全面反攻。
锤子线 Hammer
下跌末段：长下影（≥实体2–3倍）+ 小实体在顶部 + 几乎无上影。下方有需求。
上吊线 Hanging Man
与锤子线完全同形，出现在上涨末段。形状不改，位置改名。需次日确认。
流星线 Shooting Star
上涨末段：长上影 + 小实体在底部。上方有供给。
Pin Bar 价格行为社区叫法
影线主导形态的统称（Brooks/外汇圈术语）。灵魂在出现的位置，不在影线本身；主影线应 ≥ 全长 2/3 且伸进前几根K线的领地。
内包日 / 母子线 Inside Bar / Harami
第二根高低点全部缩进第一根（母线）区间：波动率收缩、休战蓄力。母线高低点=预写的触发线。
波动率压缩 Volatility contraction / Squeeze
连续十字星、内包序列、窄幅拉锯的统称：全长收窄=市场蓄力，方向选择（突破）临近。压缩的尽头常有爆发（第0001–0005课反复出现的主线概念）。
宽松口径 / 严格口径 Loose / Strict criterion
吞没形态的两种判法：连续市场（加密 7×24）开盘≈前收，第二根实体"底端相等、顶端远超"=宽松口径；两端都严格超出=严格口径。判定时必须声明所用口径。
确认 Confirmation
形态出现后，下一根K线朝形态暗示方向收盘，信号才成立。Morris"蜡烛图过滤"核心：形态是预警，确认才是行动令。

05位置与水平位（第 0003 课）

支撑区 Support zone
下方价格区域，需求反复出现。来源：前低（摆动低点）、密集成交区、整数关口。最强验证=离开后回踩不破。
阻力区 Resistance zone
上方价格区域，供给反复出现。被收盘突破后角色互换（转支撑）。
消耗效应 Exhaustion
每次触碰水平区都在消耗守方挂单：前两三次干净拒绝=验证；五六次勉强拒绝、穿透加深=突破临近。（注意与 Wyckoff 语境的 absorption"吸收供给"区分——那是另一个概念。）
假突破 / 陷阱 Fakeout / Trap
影线刺穿或短暂收破后收回。多头陷阱=假向上突破；空头陷阱/spring=假向下跌破。判定永远看实体收盘。
止损猎杀 Stop hunting
价格影线刺穿明显支撑/阻力（那里堆积着止损单）后迅速收回——假突破的"主力动机"版本。防它靠"区域+收盘"双口径：画区域不画线、判定看实体收盘。
证据重叠 Confluence
多个独立证据指向同一价位或方向（前高+整数关口+密集成交区+形态），信号质量加权——位置学的复利。
三合一检查 Shape-Position-Confirmation
本营标准流程：形状（参数过线）→ 位置（水平位语境说得通）→ 确认（次日收盘朝形态方向）。三者齐备，预警才升级为行动信号。
回抽 Retest
突破后价格回到被突破区域边缘并止住——真突破的二次确认，教科书入场点。

06市场结构（第 0004 课）

摆动高点 / 摆动低点 Swing High / Low
高点（低点）高于（低于）左右各 N 根（N 常取3–5）。结构的原子；确认天然滞后 N 根。用影线极值判定。
HH / HL / LH / LL Higher High 等
更高高点 / 更高低点 / 更低高点 / 更低低点——四象限记号。
上升趋势 / 下降趋势 Uptrend / Downtrend
严格定义：HH 与 HL 交替的序列 / LH 与 LL 交替的序列。不靠眼睛。
震荡（区间） Range
高低点重叠、序列矛盾。纪律：下沿做多、上沿做空、中间管住手。
结构破坏 Break of Structure (BOS)
收盘跌破最近 HL（上升趋势语境）：停止顺势的开关。≠ 立即反手——反手要等 LH+LL 完整序列。判定看收盘。

07量能（第 0005 课）

量价四象限 Price-volume quad
放量涨=健康趋势；缩量涨=推升乏力；放量跌=供给真实；缩量跌=卖压渐竭。量能验证价格，不预测方向。
相对量 Relative volume
今日量 ÷ 近20日均量。≥1.5–2倍=显著放量，≤0.7=显著缩量。绝不跨市场比绝对量。
高潮量 Climactic volume
加速末段的天量：最后一批人用尽最后子弹。卖出高潮=恐慌出清（底）；买入高潮=需求透支（顶）。只标记极端，不自动反转。

08多周期（第 0006 课）

自上而下 Top-down
大周期定方向（结构）→ 中周期找区域（水平位）→ 小周期找时机（形态+确认）→ 止损放小周期结构外、宽度反推仓位。顺序不可逆。
三重时间框架 Triple timeframe
周/日/4h 或 日/4h/1h 的三镜头工作流。协同（三镜头同向）=最高质量入场窗口。
周期冲突 Timeframe conflict
大周期趋势 + 小周期逆向 = 回调。裁决黄金规则：大周期结构优先，逆向信号降级处理（小仓、快进快出、止损从严）。

09训练法（第 0007 课）

检索练习 / 间隔重复 / 交错练习 Retrieval / Spacing / Interleaving
盘感的三大认知科学地基：从记忆提取（不是认出）、隔天重练、混练判断题型。
盲图盲测 Blind chart reading
遮住图表右侧→朗读七维判词→写结构预判→逐根揭示→错误归档。每天10分钟，频率>时长。
七维复盘清单 Daily checklist
结构→关键位→当日三问→量能→双K→三镜头→预案（只用"如果…那么…"句式）。
错误五分类 Error taxonomy
形状错 / 位置错 / 结构错 / 量能错 / 周期错。每月统计占比=下月训练重点。

10配色双阅读（全市场必修）

红涨绿跌＝A股、港股通、国内期货行情软件惯例；绿涨红跌＝加密交易所（多数界面可切换）、美股、国际平台惯例。同一根K线在两个世界颜色相反——读错颜色＝方向读反。本课程统一用红涨绿跌，且方向判定有三重保险：① 阴线一律空心实体（红绿色盲与黑白打印下仍可辨向）；② 单根图开=左刻度、收=右刻度；③ 永远可以回到数字本身。
