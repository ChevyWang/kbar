参考答案（先做完三题再展开）

第1题：第30根 开 79832 · 高 80108 · 低 79577 · 收 79979。①谁赢：买方小胜（实体 +147）；②战场：下影 255 点记买方战功（79577–79832 一带被承接），上影 129（80108 上方有轻供给）；③干净度：实体占比 28%——拉锯小胜，但收盘位置 76%：优势守到了终场（两个度量连读：赢得不干净，但控场到位）。记住的价位：80000–80200 整数关口带——第17根影线精确触及 80000 被拒（收 78993），第29–30根再度逼近（80200/80108）仍未收稳其上。整数关口+重复触及=下次关键战区。

第2题：①锤子类 Pin = 第7根（如实标注：疑似）（开63491 高63617 低62535 收63044）：阴线，下影 = 收盘价 63044 到最低 62535 = 509 点，实体 = 63491−63044 = 447——约 1.1 倍，达不到 2–3 倍的严格识别线（第0002课），所以按纪律只能标"疑似"。但看位置与后续：下跌第5天创出新低 62535，前一日（第6根）已经收出 678 点长下影十字（62802 被接回）——两天连续在低位接盘；随后第8–9根小实体十字重叠（蓄力——本考场无量能数据，判读只准用价格行为；数据复核显示该两根成交确实萎缩，但那是阅卷注记，不是作答依据），第10根吞没确认。参数打折，位置与确认补考——第0002课带读三的同款剧本。②流星类 Pin = 第18根（开78993 高81273 低77851 收78539）：8天上涨之后，上影 2280 = 实体 5 倍——冲 81273 被全歼；第19根高位十字、第21根大阴线完成确认。③宽松吞没 = 第10根（开62900=前收，收64532）：实体全包第9根（62900–63086），底端相等——连续市场的宽松口径（BTC 7×24，日线开盘永远≈前收）。发生在第7–9根压缩之后：压缩末端的吞没，位置加分。

第3题：70000（第12根最高价精确 70000，当日收 69335 收回——拒绝；次日才实体通过，突破后 70000 转为支撑话题）与 80000（第17根精确触及被拒；第29–30根第二次冲关，收盘仍被压在关口附近）。预案示例（句式比结论重要）："如果明日放量收盘站上 80200，则 80000 由阻力转支撑，回踩 80000 附近找做多形态；如果再度在 80000 前收出长上影，则关口第三次拒绝，向下看第21根低点 76888 一带的支撑。"

自批标准：第1题三问齐全（谁赢/战场/干净度）+ 说出 80000 一带 = 满分；第2题三处找对两处 + 参数意识（影线倍数）= 满分；第3题两关口找齐 + 预案是条件句而非方向预测 = 满分。错的地方归入错误五分类（见第 0007 课），记入你的错误日志。
