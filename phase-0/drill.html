易混形态混练：Phase 0

Phase 0 的课内训练场按课分块出题；这里把 0001–0005 教过的真实实例打乱重配、跨课混考。

01这是什么

这里是易混形态混练：把容易看错的几类形态从各课抽出来，打乱顺序混在同一轮里考你。课内训练场按课分块出题，答对率高不等于混着也能认对——交错练习（interleaving）专治「看着都会、混着就错」。

每轮随机选一个混淆组，从组内已教过的真实实例随机抽 5 张出题。多数题只画到形态完成的那一根（决策时点），之后的走势不剧透；判错立即给判读要点。

记录去哪。每次作答写入本浏览器 kbar-quizlog::drill0，与各课训练场同款：错题按 1 / 3 / 7 / 21 天到期重练，答对升档。学习进度总览页汇总各课记录（混练行待总览页纳入）。记录仅存本地，不含个人信息。
